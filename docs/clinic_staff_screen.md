# 3.1.2.2 Clinic Staff Screens Descriptions

Dưới đây là danh sách cập nhật các màn hình dành cho **Clinic Staff (Lễ tân, Điều phối viên)**, dựa trên sơ đồ luồng vận hành mới của phòng khám (Digital Clinic). Các module cũ không liên quan (như Organisation Profile, Reporting) đã được loại bỏ.

| #   | Feature             | Screen                       | Description                                                                                   |
| --- | ------------------- | ---------------------------- | --------------------------------------------------------------------------------------------- |
| 1   | User Authentication | Home Page                    | Entry point where users initiate the system sign-in process.                                  |
| 2   | User Authentication | Login Page                   | Allows clinic staff to authenticate and access the system.                                    |
| 3   | User Authentication | Login Error State            | Displays authentication errors and allows retrying login.                                     |
| 4   | Staff Dashboard     | Clinic Staff Dashboard       | Central dashboard providing an overview and quick access to daily clinic operations.          |
| 5   | Queue Management    | Clinic Queue Management Page | Displays and manages the daily patient waiting queue and current consultation status.         |
| 6   | Appointments        | Appointments Management Page | Displays and manages patient appointments, schedules, and status updates.                     |
| 7   | Appointments        | Walk-in Registration Form    | Form interface to register a new walk-in patient who arrives without a prior appointment.     |
| 8   | Patient Management  | Patient Management Page      | Displays and manages registered patients' profiles within the clinic.                         |
| 9   | Patient Management  | Edit Profile or History      | Interface to update a patient's personal information or review their past medical screenings. |
| 10  | Screening & AI      | Screenings Management Page   | Displays retinal screening sessions, tracks image uploads, and manages AI analysis flow.      |
| 11  | Screening & AI      | View Result                  | Displays detailed screening results, including retinal images and AI-generated diagnostics.   |
| 12  | Billing & Payments  | Payment Transactions Page    | Displays pending invoices, processes patient payments, and updates transaction statuses.      |
| 13  | System Settings     | Settings Page                | Configures user-specific preferences and personal account settings for the clinic staff.      |
