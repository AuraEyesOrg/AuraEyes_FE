# 3.1.2.3 Ophthalmologist Screens Descriptions

Dưới đây là danh sách cập nhật các màn hình dành cho **Bác sĩ Nhãn khoa (Ophthalmologist)**, bám sát theo luồng khám chữa bệnh và quản lý thông tin tại Digital Clinic.

| #   | Feature             | Screen                          | Description                                                                                           |
| --- | ------------------- | ------------------------------- | ----------------------------------------------------------------------------------------------------- |
| 1   | User Authentication | Home Page                       | Entry point where users initiate the system sign-in process.                                          |
| 2   | User Authentication | Login Page                      | Allows ophthalmologists to authenticate and access their dashboard.                                   |
| 3   | User Authentication | Login Error State               | Displays authentication errors and allows retrying login.                                             |
| 4   | Doctor Dashboard    | Ophthalmologist Dashboard       | Central dashboard providing an overview of daily appointments, patient queues, and tasks.             |
| 5   | Profile Management  | Ophthalmologist Profile Page    | Displays the doctor's personal and professional profile information.                                  |
| 6   | Profile Management  | Update Profile Page             | Interface allowing the doctor to update their personal information and credentials.                   |
| 7   | Patient Management  | Patient Management Page         | Displays a list of patients assigned to the doctor.                                                   |
| 8   | Consultation        | Patient Case Page               | The main clinical interface detailing a specific patient's current visit and medical case.            |
| 9   | Consultation        | Patient Profile Page            | Displays the patient's personal details and historical medical records.                               |
| 10  | AI Diagnostics      | AI Analysis Results Page        | Displays retinal images and the corresponding AI-generated diagnostic results.                        |
| 11  | AI Diagnostics      | Verify AI Analysis Results Page | Interface for the doctor to review, confirm, or override the AI diagnostic findings.                  |
| 12  | Screenings          | Screenings Management Page      | Displays the list of the doctor's assigned screenings and appointments.                               |
| 13  | Consultation        | Submit Diagnosis                | Interface to submit the final clinical diagnosis, notes, and medical prescriptions post-consultation. |
| 14  | Staff Leave         | Leave Requests Page             | Form interface to submit leave of absence requests and track their approval status.                   |
| 15  | Aura Network        | Network Page                    | Access to the Aura Network platform for professional collaboration or external data tracking.         |
