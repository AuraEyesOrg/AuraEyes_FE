# 3.1.2.1 System Admin Screens Descriptions

Dưới đây là danh sách cập nhật các màn hình dành cho System Admin, dựa trên luồng vận hành mới của phòng khám (Digital Clinic), loại bỏ các module thừa (Contracts, Organisations, v.v.).

| #   | Feature             | Screen                         | Description                                                                                   |
| --- | ------------------- | ------------------------------ | --------------------------------------------------------------------------------------------- |
| 1   | User Authentication | Home Page                      | Entry point where users initiate the system sign-in process.                                  |
| 2   | User Authentication | Login Page                     | Allows administrators to authenticate and access the system dashboard.                        |
| 3   | User Authentication | Login Error State              | Displays authentication errors and allows retrying login.                                     |
| 4   | Admin Dashboard     | System Admin Dashboard         | Central dashboard providing an overview and quick access to all administrative functions.     |
| 5   | Staff Management    | Staff Management Page          | Displays and manages clinic staff members (receptionists, coordinators, ophthalmologists).    |
| 6   | Staff Management    | Create Staff Form              | Form interface to add and register a new staff member into the system.                        |
| 7   | Staff Management    | Staff Profile Detail           | Displays detailed profile and employment information of a specific staff member.              |
| 8   | Leave Requests      | Leave Requests Management Page | Displays and allows processing (approve/reject) of leave requests submitted by staff members. |
| 9   | Patient Management  | Patient Management Page        | Displays and manages registered patients within the clinic system.                            |
| 10  | Patient Management  | Patient Medical History        | Displays a comprehensive view of a patient's historical medical records and past visits.      |
| 11  | Billing & Payments  | Payment Transactions Page      | Displays system billing, invoices, and payment transaction records.                           |
| 12  | Billing & Payments  | Order Detail                   | Displays detailed information about a specific transaction or generated invoice.              |
| 13  | Scheduling          | Scheduling Management Page     | Manages working slots, blocks slots, schedule templates, and allows booking for patients.     |
| 14  | Permissions         | Permissions Management Page    | Displays and manages system roles, role assignments, and access permissions.                  |
| 15  | Permissions         | Create Permission Form         | Interface for creating a new permission node in the system.                                   |
| 16  | Audit Logs          | Logging Management Page        | Tracks system activities and displays detailed JSON logs for security auditing.               |
| 17  | Network Management  | Network Management Page        | Manages Aura Network configurations and data syncing.                                         |
| 18  | System Settings     | Setting Management Page        | Configures global system settings, preferences, and operational parameters.                   |
